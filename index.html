:hover sehri

Sehrli Qo'l: Sichqoncha tekkanda nima bo'ladi?

Sichqonchangizni uxlab yotgan robota yaqinlashtiring va uni uyg'oting!

Boshqaruvni robot ustiga keltiring!
Holat: Uxlab yotibdi 😴
Sehr qanday ishlaydi?
.robot:hover {
transform: translateY(-15px); /* Yuqoriga sakraydi */
filter: drop-shadow(0 0 20px #38bdf8); /* Nurlanadi */
}
💡

:hover — sichqoncha biror element ustiga borganda ko'rinishni o'zgartiruvchi sehrli eshikdir!

opacity sehri

Ko'rinmaslik Plashi: Shaffoflik siri

Slayderni suring: 0 — ko'rinmas arvoh, 1 — haqiqiy qahramon!

✨ ⭐ 🌟 🪐
opacity: 1
🔮 Shaffoflik darajasi: 1.00
.arvoh-plashi {
opacity: 1.0;
}
💡

opacity qiymati 0 (mutlaqo ko'rinmas) dan 1 (to'liq ko'rinuvchi) gacha bo'ladi!

transform: scale() sehri

Sehrli Lupa: Kattalashtirish va Kichraytirish

Elastik sandiqchani kattalashtirib, uning qanday sakrashini tomosha qiling!

scale(1.0)
🔍 Kattalashtirish koeffitsienti: 1.0x
.sehrli-sandiq {
transform: scale(1.0);
}
💡

transform: scale() elementni markazidan boshlab kattalashtiradi yoki kichraytiradi!

box-shadow sehri

Quyosh va Soya: 3D Parvoz va Balandlik

Kosmik kemani havoga ko'taring: soya uzoqlashgani sari kema balandroq uchadi!

+
🚀 Parvoz balandligi (Soya): Baland (30px)
✨ Nurlanish rangi:
.uchuvchi-tareka {
box-shadow: 0 25px 40px #0284c7;
}
💡

box-shadow orqali elementga yumshoq soya yoki sehrli nur berib, uni ekrandan 3D ko'tarish mumkin!

transition sehri

Sakrash emas, Silliq Harakat! (Poyga)

Ikkita kosmik kema poygasi: transitionsiz kema sakraydi, transitionli kema esa silliq uchadi!

❌ Transitionsiz Qo'pol va to'satdan sakraydi
🚀 Tezkor-1
🏁 MARRA
✅ Transition bor! 0.6 soniyada silliq
🛸 Silliq-2
🏁 MARRA
⏱️ Silliq o'tish vaqti (Duration): 0.6s
.silliq-raketa {
transition: 0.6s ease-in-out;
}
💡

transition — animatsiyaning vaqt o'lchovchisi bo'lib, o'zgarishlarni qo'pol sakrashdan silliq harakatga aylantiradi!

Super Birlashuv

Barcha Sehrlarni Birlashtiramiz!

:hover + scale + box-shadow + opacity + transition = Super Raketa!

Sichqonchani raketa ustiga olib keling!
.super-raketa {
